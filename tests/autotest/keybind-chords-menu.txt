; Controls page with a modifier-only and a multi-key binding. Attack move takes Ctrl with Shift: both keys go down, and
; releasing them with no other key captures the chord alone, and the notice shows it while the keys are held. Assign
; keeps the trigger the dropdown shows, which is Press here because the row held a press. Guard refuses the chord, since a
; press command cannot use it, then takes Alt+Ctrl+X (the game writes the modifiers as Alt, Ctrl, Shift).
; The control scheme and the starting Attack move key come from the user folder's KEYBOARDMD.INI.
; Shots: chord-held, chord-released, chord-assigned (Attack move's row), chord-refused (the notice on Guard),
; combo-assigned (Guard's row). OK then saves the file to the user folder's KEYBOARDMD.INI.

; Vehicles and infantry boarding a Soviet Amphibious Transport (SAPC: Passengers=12, SizeLimit=6, Hover, Naval=yes).
; Three trials on Lostlake.mmx, each with a War Miner (SMIN), a Rhino (HTNK), a Size 3 tank (MGTK) and a rifleman (E1, Size 1).
; The transport stands on land (78,45), on a beach cell (80,47, a shore piece) and on open water (82,45). Each trial's enter
; order reaches every player object of its type that is outside, so objects that did not board are killed before the next
; trial. Boarded objects are in limbo and are not killed. The terrain of each transport cell is logged.
; Run from the repository root (the debug cheats are needed for DebugRevealMap):
;   powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/run_autotest.ps1 -Build agent8 -Map Lostlake.mmx -Country 8 -Script src-agent8/tests/autotest/amphib-transport-vehicles.txt -Settings "[Options]<newline>DebugMode=yes" -Seconds 900 -Filter "AUTOTEST|Exception"

; Observed on the final build: HTNK and SMIN board the beach and the water transport; MGTK and E1 stay outside those trials,
; which is the open part of the radio handshake. In the land trial no passenger left its starting cell (Guard), so that
; result is not a load result: the start cells may be cut off from the transport, and the layout has not been checked.

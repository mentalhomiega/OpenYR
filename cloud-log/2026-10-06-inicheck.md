## Findings while reading

- The 2026-10-04 note that `Territory%02d` is zero-padded did not hold up here: `code/` has no `Territory%02d` format. The only zero-padded numbered ini keys I found are the five `Tile%02d` keys in `code/isotype.cpp` (`Anim`, `XOffset`, `YOffset`, `AttachesTo`, `ZAdjust`), all exported now.
- `Tile%02d` keys are read from a tile set's own section, but the checker does not read theater control files, so they have no effect yet.
- A type with no rules section still has an art section (every animation does). `Check_Art` places such types from the rules lists alone.
- When a rules section holds `Image=` twice, the checker uses the last line. I did not check which line the engine's INI reader keeps.

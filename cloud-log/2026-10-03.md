### Findings that still need a fix

All are proposals read from the code; none were checked in game.

NumberOfDocks (280307cb):

1. `code/building.cpp:594`, `:3140`, `:3836`, `:4001`: `Transmit_Message(RADIO_TETHER)` has no target, so it goes to radio slot 0. At a pad with several docks, the tether can reach the aircraft in slot 0 instead of the one that just docked. Fix: pass `from`, `base` or `air` as the target.
2. `code/building.cpp:499-517`, `:532-536`, `:564-566`, `:4654-4664`, `:5021-5040`, `:5059-5061`, `:5230`: these still act on `Contact_With_Whom()` (slot 0) or send untargeted messages. A one-dock building behaves as before. At a multi-dock building, the bump-off at `:514-517` and the restart of rearming at `:5059-5061` can address the wrong aircraft. Fix: loop over `Link(slot)` as `Do_MISSION_REPAIR` now does, or target the sender.
3. `code/building.cpp:6187`: once reloading stops, the rearm loop sends `RADIO_REPAIR`. `TechnoClass` answers it by repairing for money (`code/techno.cpp:1238-1290`), and `FootClass` refuses only while `NavCom` is set (`code/foot.cpp:2279`). A `UnitReload` pad may therefore now repair aircraft. `manual/content/keys/helipad.md:12` says repair comes from `UnitRepair=`. Check in game, then fix the code or the page.
4. Retracted: the first run listed untargeted `RADIO_OVER_OUT` at `code/building.cpp:1582`, `:1600`, `:1969` and `:5131`. These run when a wall becomes an overlay and when construction finishes; neither involves a docked aircraft, so no fix is needed.

Projectiles (2027ff52):

13. `code/bullet.cpp:1230`: the cliff test compares ground heights only (`Map[SourceCoord]` and `Map[LastCell]`), never the projectile's altitude. A shell fired from a high bridge, or a shot from an aircraft, can explode where the ground rises under it. Fix: also require the projectile to be at or below the new cell's surface.
14. `code/bullet.cpp:1234-1240`: the wall test has no altitude limit; the code it replaced stopped shots only below height 100. A `SubjectToWalls=yes` shot from an aircraft explodes over the first wall its ground track crosses. Keep a height limit unless the original has none, and say which on the `SubjectToWalls` page.
15. `code/bullet.cpp:1236` with `:1056`: allied-wall transparency needs `Payback`, which `Detach` clears when the firer dies. A shell from a unit killed after firing explodes on an allied wall, against `manual/content/keys/alliedwalltransparency.md:10`. Fix: store the firing house in the bullet and serialize it, or narrow the page.

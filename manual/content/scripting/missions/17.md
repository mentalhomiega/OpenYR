## Why the new Script does not start

A team moves to its next Script line only when the current line raises its [advance flag](/systems/ai-team-execution/#the-script-cursor), and this line never raises it. This line leaves the team before the first line of the new Script. No line runs from there, so the team does nothing on every later turn.

## The one way the new Script runs

The team runs the new Script only after it is [sent back to regroup](/systems/ai-team-execution/#every-regroup-rewinds-the-script) and starts again. It then runs the new Script from its first line.

A team is sent back to regroup when it drops under strength after starting. A [`Reinforce=no`](/keys/reinforce/) team is never under strength once it has started, so only a `Reinforce=yes` team can ever run the new Script.

## Finding a Script's number

A Script's number can differ from its place under `[ScriptTypes]`. Scripts are numbered in the order the game first reads their names:

1. Each Script that a TeamType's `Script=` names, in the order the TeamTypes are read. TeamTypes are read from `AI.INI`, then from `AIFS.INI` when Firestorm is enabled, then from the map, each file in its `[TeamTypes]` order.
2. Each remaining Script listed under `[ScriptTypes]`, in the same file order.

A Script named again later keeps the number it was first given.

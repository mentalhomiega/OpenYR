Each member receives a forced scatter request with no threat to move away from. A vehicle or soldier that accepts it is sent to a nearby clear cell.

The mission-level [`Scatter`](/keys/scatter/#scope-mission-behavior) setting describes which missions and object types refuse a scatter request. A member also ignores this line under **any of:**

- it is a vehicle that already has a destination or is turning;
- it is a soldier that is already walking, unless its type is [`Fraidycat=yes`](/keys/fraidycat/) and its mission allows scattering;
- it is a soldier in the middle of an animation that cannot be interrupted;
- it is an aircraft. An aircraft never moves to a new cell for this line. If its mission allows scattering, it returns to its idle behavior instead.

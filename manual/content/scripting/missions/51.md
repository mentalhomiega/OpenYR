---
type: mission
id: TMISSION_PLAY_ANIM
title: "Play Anim"
summary: "Attaches an animation to every member so that it travels along with them."
valid_values:
  - "One number that holds both parameters: the loop count times 65536, plus the animation's position in the registered animation list, counted from `0`. `131079` plays animation `7` with a loop count of `2`."
caveats:
  - "Each member gets its own copy of the animation, attached so that it moves with the member. The animation is created on the turn the line is reached and not again, so a member that joins the team afterward gets none."
  - "The loop count multiplies the animation type's `LoopCount`. A loop count below `1` counts as `1`."
  - "The animation is not made harmless. An animation type that sets `Damage` deals it where the member stands, to the member itself as well."
  - "An animation position outside the registered list creates nothing, and the team still takes the next line."
  - "The line does not hold the team: it runs once and the team takes the next line of its script on the following turn."
related:
  - type: action
    id: TACTION_PLAY_ANIM
---

[`LoopCount`](/keys/loopcount/) explains how the loop count and the animation's own setting combine. [`Damage`](/keys/damage/#scope-animtype) sets the damage an animation deals. The [Play Anim At](/mapping/actions/taction-play-anim/) trigger action plays an animation at a waypoint without that damage.

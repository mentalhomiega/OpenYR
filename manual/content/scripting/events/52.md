---
type: event
id: TEVENT_CREDITS_BELOW
title: Credits below...
summary: Satisfied while the house that owns the trigger has no more than the given amount of money, counting stored Tiberium.
valid_values:
  - A number of credits. Holding exactly this amount satisfies the event.
caveats:
  - The amount compared is the house's cash plus the value of the Tiberium it holds in storage. A house with little cash does not satisfy the event while its stored Tiberium keeps the total above the amount.
  - A house that starts the scenario at or below the amount satisfies the event at once. To catch a house running short, enable the trigger later, or give it another event that is satisfied only later.
  - The event puts its tag on the list of the house that owns the trigger. That list is offered every frame, so the event is satisfied from the first frame the house is at or below the amount.
  - Avoid a persistent tag. Unless it is the first tag on that house's list, the list offers a persistent tag again each time it fires. While the house stays at or below the amount and the trigger is neither disabled nor destroyed, the trigger fires without end and the game hangs.
  - A semi-persistent tag fires only while exactly one object or map cell holds it, and this event attaches the tag to neither. Use a volatile tag.

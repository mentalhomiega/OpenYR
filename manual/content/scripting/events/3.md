## Where the trigger sits and what it is offered

This event can attach only to a house, so its tag joins the list of the house that owns the trigger. That list is offered something every frame, but the offer names nothing in particular. The only other offer the list receives names [Attacked by any house](/mapping/events/tevent-attacked/), when [the house's base is damaged](/systems/base-attacked/#what-the-house-announces). Neither offer names Thieved by..., so the event is never satisfied.

## The mark it would read

If an offer did reach it, the event would test whether the named house has been marked as robbed. The mark has nothing to do with money. It is set on a house when it [loses a structure to an engineer](/systems/capture/#capturing-a-non-allied-structure), and by nothing else: a stolen vehicle does not set it. Nothing clears the mark, so such a test would pass at any time after the house's first loss, not only at the moment of it.

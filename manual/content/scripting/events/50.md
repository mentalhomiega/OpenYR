---
type: event
id: TEVENT_PICKUP_CRATE_ANY
title: Pickup Crate (any)
summary: Satisfied at the start of the frame after any object collects a crate whose overlay type sets `CrateTrigger=yes`.
caveats:
  - Only a crate whose overlay type sets `CrateTrigger=yes` counts. The overlay type alone decides this, whether the map placed the crate or it appeared during play.
  - The event is offered once, at the start of the frame after the collection. Several such crates collected in the same frame produce a single offer.
  - If a [Pickup Crate](/mapping/events/tevent-pickup-crate/) trigger on the collector's tag removes the collector, the crate is not collected and this event is not offered.
  - The offer names no object. The trigger cannot tell which object collected which crate, and actions that work on the object a trigger is attached to have nothing to work on.
  - On a persistent tag, the event is [remembered](/systems/trigger-springing/#remembering-a-satisfied-event) from the first collection onward. A trigger whose only event this is then fires every frame for the rest of the scenario.
  - A tag that fires on this offer receives no other offers from the general list in that frame.
  - A semi-persistent tag fires only while exactly one object or map cell holds it, and this event attaches the tag to neither. Use a volatile or a persistent tag.

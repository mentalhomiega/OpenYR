---
type: event
id: TEVENT_ATTACKED_BY
title: Attacked by (house)...
summary: Fires when an object of the named house damages the tagged object without destroying it.
valid_values:
  - A house number, as scenario object records define it. Only the attacker's own house counts, not its allies.
  - If the named house is not in the game, or names a start position that no house holds, the event is never satisfied.
  - If several houses play the named country, only damage from the first of them the game created counts.
caveats:
  - Damage that credits no attacker never satisfies the event.
  - The hit that destroys the object does not satisfy the event, so the event never reports a kill. Healing does not satisfy it either, and neither does splash damage that is reduced to nothing by its distance from the impact.
  - The event is never remembered, so a persistent tag tests it again on every offer. On a trigger that also waits for another temporal event, that event must already be remembered when the hit lands. Trigger springing says when an event is remembered.
related:
  - type: system
    id: trigger-springing
  - type: event
    id: TEVENT_ATTACKED
---

Only the damaged object's tag is offered this event. [Attacked by any house](/mapping/events/tevent-attacked/) has two further offers that this event lacks: one through the owner's house list when a structure is damaged, and one when the object is destroyed by an attacker.

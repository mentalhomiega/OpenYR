---
type: event
id: TEVENT_AMBIENT_GREATER_THAN
title: Ambient light >= ...
summary: Satisfied while the scenario's ambient light is at or above the given percentage of full daylight.
valid_values:
  - A percentage, where 100 is the light level a map writes as `Ambient=1`. The event is satisfied while the current level is at or above the number.
caveats:
  - The event is satisfied from the first frame when the map's starting level already meets the number, for example a number of 100 on a map with `Ambient=1`.
  - The level is not capped at 100. A map with `Ambient=` above 1 starts above 100, for example 135 for `Ambient=1.35`.
  - The event tests the current level, which fades toward a new target at the pace `AmbientChangeStep` and `AmbientChangeRate` set.
  - An ion storm fades the level toward the map's `IonAmbient` and back to its ordinary level when the storm ends.
  - Set ambient light... sets a new target level. During an ion storm it changes only the level the map returns to when the storm ends. Set ambient step... and Set ambient rate... change the fade.
  - The event is tested every frame, so a persistent tag fires every frame while the level stays at or above the number.
  - Give the trigger a volatile or a persistent tag. This event puts its tag only on the general list, which does not count toward the attachments a semi-persistent tag waits on. A semi-persistent tag therefore never fires unless an object or a map cell also holds it.

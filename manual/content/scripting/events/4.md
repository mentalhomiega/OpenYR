type: event
id: TEVENT_DISCOVERED
title: Discovered by player
summary: Satisfied when the tagged object is first discovered by a human player other than its owner, and again when the object is destroyed by an attacker.
caveats:
  - The event fires on discovery only for the first human player other than the owner to discover the object. Later discoveries by other human players do not fire it until the human players' discovery marks on the object are [cleared](/systems/map-visibility/#what-the-other-houses-know), for example when a computer house's object goes into limbo. The owner discovering its own object never fires it.
  - Discoveries made while the scenario is being set up never fire the event, and the object then counts as already discovered. A tagged object standing inside the player's opening view therefore never fires the event on discovery.
  - Outside a campaign, every human player discovers most objects as soon as they are placed on the ground, whether or not they are in view. [What the other houses know](/systems/map-visibility/#what-the-other-houses-know) lists the exceptions, and an aircraft placed in flight is not discovered this way. A tagged object discovered this way after setup therefore fires the event at once if a human player other than its owner is in the game.
  - In a campaign, the player can also discover an object without firing the event, when its position stops being shrouded. [What the other houses know](/systems/map-visibility/#what-the-other-houses-know) describes this case.
  - The event also fires when the tagged object is destroyed and an attacker is credited with the kill. This does not depend on the object's owner or on discovery, so a tagged object of any house satisfies the event by being destroyed.
  - A tag that rides only on a map cell is never offered this event.
  - On a persistent tag, the event stays marked once satisfied, so the trigger fires on every later offer the tag receives, as [remembering a satisfied event](/systems/trigger-springing/#remembering-a-satisfied-event) describes.

## The two offers

The object's tag is offered this event on discovery when **all of:**

- the house discovering the object is a human player;
- that player has not discovered the object before;
- that player does not own the object;
- no human player other than the owner has discovered the object yet;
- the scenario is no longer being set up;
- the object has a tag.

The object's tag is offered this event again when the object is destroyed, under **all of:**

- the object is still in the game;
- it has a tag;
- an attacker is credited with the kill.

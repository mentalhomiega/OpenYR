type: event
id: TEVENT_ENTER_RED_ANY
title: Quarter health (any source)
summary: Fires when damage takes the tagged object from above the condition red fraction of its maximum strength to below it, whether or not an attacker is credited for the damage.
caveats:
  - The line is the `ConditionRed` fraction of the object type's maximum strength. It is a quarter only when `ConditionRed=.25`.
  - Except for a cyborg's reprieve, described above, the object must start above the line and end below it. A hit that starts or ends exactly on the line does not satisfy the event.
  - The hit that destroys the object satisfies the event if the object was above the line before the hit. The event fires before any destruction event.
  - A hit that crosses both this line and half strength fires this event and not Half health (any source).
  - A hit with an attacker credited satisfies this event as well as Quarter health (combat only). The combat-only event is offered first, and this event is not offered if a trigger fired by that first offer removes the object.

[`ConditionRed`](/keys/conditionred/) also decides [how often the half health events can fire](/mapping/events/tevent-enter-yellow-any/#the-quarter-health-line-usually-takes-the-blow-first).

A standing [`Cyborg=yes`](/keys/cyborg/) soldier that survives a killing hit fires this event, whatever its strength before the hit and wherever its new strength falls. The hit counts as a drop below this line, not as a destruction, so destruction events do not fire for it.

---
type: event
id: TEVENT_GLOBAL_SET
title: Global is set...
summary: Satisfied while the named global variable is set.
valid_values:
  - A global variable number from 0 to 49. The rules file can name each number in its `[VariableNames]` section, but the event stores only the number.
caveats:
  - The event tests the variable's current state, not the moment it changed, so it is satisfied for as long as the variable stays set. A persistent trigger holding only this event fires every frame during that time.
  - When a global changes, every trigger with an event naming it restarts its elapsed-time countdown. Pairing this event with an elapsed-time event therefore measures the delay from the change.
  - Globals carry into the next campaign mission, so a global set in an earlier mission is already set when a later mission starts. [What survives the boundary](/systems/campaign-progression/#what-survives-the-boundary) covers the handover.
  - Keep the number between 0 and 49. For any other number, the result of the test is unpredictable.
  - Give the trigger a volatile or a persistent tag. This event puts its tag only on the general list, which does not count toward the attachments a [semi-persistent tag](/systems/trigger-springing/#tag-lifetimes) waits on. A semi-persistent tag therefore never fires unless it also rides on an object or a cell.

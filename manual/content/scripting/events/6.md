type: event
id: TEVENT_ATTACKED
title: Attacked by any house
summary: Satisfied when an attacker of any house damages or kills the tagged object.
caveats:
  - Any attacker counts, including an ally or another object of the same house. The exception is a [`TypeImmune=yes`](/keys/typeimmune/) type, which takes no damage from another object of its own type and house.
  - Damage that credits no attacker satisfies nothing. The damage structures take while their house is short of power is one example.
  - A hit that deals no damage satisfies nothing. A web, which pins infantry without damaging it, is one example. Healing never satisfies the event.
  - The hit that destroys the object does not offer the event as damage. Recording the kill offers it instead when the kill credits an attacker, so a fatal hit still satisfies the event once. Being crushed, and dying inside a transport that an attacker destroys, satisfy it the same way.
  - The event is never [remembered](/systems/trigger-springing/#remembering-a-satisfied-event), so on a persistent tag each hit is tested afresh.

## The offer made to a house

Damage to a structure also offers this event to [every tag on its owner's house list](/systems/base-attacked/#what-the-house-announces). The linked section gives the conditions. Among them, the structure must not be [`Insignificant=yes`](/keys/insignificant/#scope-aircrafttype) or a deployed vehicle. Damage to a vehicle, aircraft or infantry makes no such offer.

This event does not put a tag on a house list by itself. A tag receives the house offer only when [another event on it puts the tag on that list](/systems/trigger-springing/#tags-triggers-and-events-in-brief), usually [Any Event](/mapping/events/tevent-any/). The trigger then fires for damage to any qualifying structure the house owns, as well as for damage to the object the tag rides on.

The house offer names no object. Actions on the trigger that work on the object the trigger is attached to have nothing to work on.

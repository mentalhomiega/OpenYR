---
type: event
id: TEVENT_ENTER_RED
title: Quarter health (combat only)
summary: Fires when damage with an attacker credited for it takes the tagged object from above the ConditionRed fraction of its maximum strength to below it.
caveats:
  - The line is [`ConditionRed`](/keys/conditionred/) times the object type's maximum strength. It is a quarter only when `ConditionRed` is `.25`, which is not the key's default.
  - The object must be above the line before the hit. An object standing exactly on the line does not fire the event when it drops below.
  - A hit that destroys the object fires the event if the object was above the line, before the destruction events.
  - This event requires an attacker credited for the damage, whatever the weapon. Damage with no attacker fires only [Quarter health (any source)](/mapping/events/tevent-enter-red-any/).
  - On a persistent tag, the event stays marked once satisfied, so the trigger fires on every later offer the tag receives, as [remembering a satisfied event](/systems/trigger-springing/#remembering-a-satisfied-event) describes.

[`ConditionRed`](/keys/conditionred/) also decides [which hits are left to the half health events](/mapping/events/tevent-enter-yellow/#the-quarter-health-line-usually-takes-the-blow-first), because a hit that crosses both lines fires only this event.

When a standing [cyborg](/keys/cyborg/) survives a hit that would have killed it, that hit fires this event whatever the cyborg's strength was before it, as long as an attacker is credited. The cyborg is not destroyed, so a trigger waiting for its destruction does not fire. Forced damage, such as a laser fence or a hunter-seeker, gets no reprieve and destroys the cyborg.

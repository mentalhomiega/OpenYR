---
type: event
id: TEVENT_LIMPED
title: Limped
summary: Satisfied when a weapon whose warhead sets `LimpetFactor` attaches its house's limpet mark to the tagged object.
caveats:
  - Any weapon whose warhead sets `LimpetFactor` to `1` or more satisfies the event when it attaches a mark, whatever object fires it and whichever house owns the target.
  - An object holds at most one mark from each house, so each house satisfies the event on a given object once. A later shot from the same house attaches nothing and does not satisfy the event.
  - Once the object's [marks are removed](/keys/limpetfactor/#removing-a-mark), the same house can attach a new mark and satisfy the event again.
  - Structures, aircraft and infantry can be marked as well as vehicles, and each satisfies the event. Only a marked vehicle is slowed.
  - On a persistent tag, the event is [remembered](/systems/trigger-springing/#remembering-a-satisfied-event) after the first mark.

The [`LimpetFactor`](/keys/limpetfactor/) page explains what a mark does to the object holding it and what removes it. In the shipped rules, the limpet drone deploys into a limpet mine, and the mine fires the weapon that attaches the mark.

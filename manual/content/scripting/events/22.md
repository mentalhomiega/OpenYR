---
type: event
id: TEVENT_BUILD_AIRCRAFT
title: Build Aircraft Type...
summary: Never satisfied, because no part of the game offers this event to a trigger.
valid_values:
  - An AircraftType. The house records only the type of the last aircraft it produced, but the event never reads that record.
caveats:
  - Unlike the other three build events, this event is not exempt. Only an offer that names it could satisfy it, and nothing makes one. The event puts its tag on the house list of the trigger's house, whose offers name either nothing in particular or the attacked event.
  - A trigger with this event never fires unless forced, even when its other events are satisfied, because every event on a trigger must be satisfied.
  - Only [Force Trigger](/mapping/actions/taction-force-trigger/) can run the trigger's actions, because it does not test the trigger's events.
  - The record is set only when a finished aircraft leaves the factory that produced it. An aircraft the house gets otherwise, such as a reinforcement or a capture, leaves it unchanged, and nothing clears it.
related:
  - type: system
    id: trigger-springing
  - type: system
    id: production
  - type: action
    id: TACTION_FORCE_TRIGGER
---

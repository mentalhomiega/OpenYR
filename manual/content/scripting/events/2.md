## What a structure's tag is offered instead

When infantry reaches the structure it was sent into, the structure's tag is offered [Entered by...](/mapping/events/tevent-player-entered/) before anything about the soldier is checked. For a spy, that is the only offer the structure's tag receives. It names a different event, so a Spied upon event on the same tag stays unsatisfied. Spied upon attaches only to objects, so its trigger has no other place to wait for an offer.

An [`Agent=yes`](/keys/agent/) soldier then [records its house as spying on the structure](/systems/capture/#infiltrating-it), and the structure's tag gets no further offer.

To react to a spy, put Entered by... on the structure's tag and name the spy's house. It fires for any soldier of that house that walks into the structure, not only for a spy.

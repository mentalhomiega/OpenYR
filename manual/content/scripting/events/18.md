---
type: event
id: TEVENT_EVAC_CIVILIAN
title: Civilians Evacuated
summary: Never satisfied, because no part of the game offers this event to a trigger.
caveats:
  - Only an offer that names this event could satisfy it, and nothing makes one. The event puts its tag on the house list of the trigger's house, whose offers name either nothing in particular or the attacked event.
  - A trigger with this event never fires unless forced, even when its other events are satisfied, because every event on a trigger must be satisfied.
  - Only [Force Trigger](/mapping/actions/taction-force-trigger/) can run the trigger's actions, because it does not test the trigger's events.
  - Evacuating a [civilian](/keys/civilian/) records the evacuation this event would test for, but it does not offer the event.
related:
  - type: system
    id: trigger-springing
  - type: key
    id: Civilian
  - type: action
    id: TACTION_FORCE_TRIGGER

## The two announcements

An electromagnetic pulse satisfies the event on each object it catches, and [What a pulse reaches](/systems/emp-pulse/#what-a-pulse-reaches) lists those objects. Among infantry, a pulse catches only a [cyborg](/keys/cyborg/). These caught objects satisfy the event without being stunned:

- an object whose type is immune, such as one with [`ImmuneToEMP=yes`](/keys/immunetoemp/); the pulse leaves it unaffected;
- an aircraft caught [off the ground](/systems/emp-pulse/#aircraft) whose type is not immune; it crashes;
- a limpet mine; the pulse destroys it.

A [`Webby=yes`](/keys/webby/) warhead satisfies the event on each infantry it pins. Vehicles, aircraft and structures are never pinned and do not satisfy the event. Infantry whose type sets [`IsWebImmune=yes`](/keys/iswebimmune/) is not pinned either: it takes the hit as ordinary damage and does not satisfy the event.

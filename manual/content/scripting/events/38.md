type: event
id: TEVENT_FIRST_DAMAGED
title: First damaged (combat only)
summary: Fires when damage with an attacker credited for it lands on the tagged object while the object is at its maximum strength.
caveats:
  - Earlier damage does not matter. Any credited hit that lands while the object is at its type's maximum strength fires it, so an object repaired to full and hit again fires it again.
  - A hit that destroys an undamaged object in one blow also fires the event, before the destruction events.
  - This event requires an attacker credited for the damage, whatever the weapon. Damage with no attacker, such as the damage a structure takes while its owner is short of power, fires only [First damaged (any source)](/mapping/events/tevent-first-damaged-any/).
  - Repair and healing never fire the event.
  - An airborne aircraft that an [EM pulse](/systems/emp-pulse/) brings down fires the event whatever its strength, when the pulse has a firer to credit. An aircraft brought down by an [ion storm](/systems/ion-storms/) has no attacker, so it fires only the any-source form.
  - On a persistent tag, the event stays marked once satisfied, so the trigger fires on every later offer the tag receives, as [remembering a satisfied event](/systems/trigger-springing/#remembering-a-satisfied-event) describes. Those offers include the ones that follow in the same hit, so one hit can fire the trigger several times.

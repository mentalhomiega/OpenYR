---
type: event
id: TEVENT_CREDITS
title: Credits exceed...
summary: Satisfied while the house that owns the trigger has at least the given amount of money, counting stored Tiberium.
valid_values:
  - A number of credits. Holding exactly this amount satisfies the event, despite the event's name.
caveats:
  - The amount compared is the house's cash plus the value of the Tiberium it holds in storage. A house whose cash is below the amount still satisfies the event when its stored Tiberium makes up the difference.
  - The event puts its tag on the list of the house that owns the trigger. That list is offered every frame, so the event is satisfied from the first frame the house reaches the amount.
  - Do not use a persistent tag. When a persistent tag fires from the house list, the list offers it again at once, unless it is the first tag on that list. While the house keeps the amount, the trigger fires without end and the game hangs.
  - A semi-persistent tag fires only while exactly one object or map cell holds it, and this event attaches the tag to neither. Use a volatile tag.

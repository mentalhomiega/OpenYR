## The quarter health line usually takes the blow first

When one hit crosses both the half strength line and the quarter health line, only [Quarter health (combat only)](/mapping/events/tevent-enter-red/) fires. [`ConditionRed`](/keys/conditionred/) sets the quarter health line, so it decides which hits are left to this event.

At the built-in `ConditionRed` of `.5`, both lines sit at half strength. This event then fires only for a hit that lands while the object is at exactly half its maximum strength, rounded down.

Moving `ConditionRed` away from `.5` leaves this event more hits:

- Below `.5`, it fires for a hit that takes the object below half strength but not below the `ConditionRed` line.
- Above `.5`, it fires for a hit that takes the object below half strength from a strength at or below the `ConditionRed` line.

---
type: event
id: TEVENT_NONE
title: "-No Event-"
summary: Never satisfied, so a trigger that holds it fires only when Force Trigger forces it.
caveats:
  - Every event on a trigger must be satisfied, so adding this event to a trigger stops it firing on its own for the rest of the scenario.
  - Force Trigger runs an enabled trigger's actions without testing its events, and does nothing to a disabled trigger. It is the only way to run the actions of a trigger that holds this event.
  - Forcing the trigger leaves its tag in place. If a trigger in that tag holds Allow Win, the hold that tag places on a house's victory stays in place after the forced firing. [Holding back the victory](/systems/trigger-springing/#holding-back-the-victory) says what lifts the hold.
related:

    id: trigger-springing

    id: TACTION_ALLOWWIN
  - type: event
    id: TEVENT_ANY

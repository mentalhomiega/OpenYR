---
type: event
id: TEVENT_PICKUP_CRATE
title: Pickup Crate
summary: Satisfied when the object holding the tag collects a crate whose overlay type is a trigger crate.
caveats:
  - Only a crate whose overlay type sets `CrateTrigger=yes` satisfies the event. The overlay type alone decides, whether the crate was placed by the map or appeared during play.
  - The tag must be on the collecting object. A tag on the crate's cell is never offered this event, so attach the tag to the objects that will collect the crate.
  - Only infantry, walkers, hovercraft and driven vehicles collect crates. Collecting a crate, on the Crates page, lists which of them refuse a crate's cell.
  - The collector's tag is offered the event before the crate's result is chosen. If a trigger fired by that offer destroys the collector, the crate stays on the map and gives no result.
  - On a persistent tag the event is remembered as soon as it is satisfied, so the trigger counts it as satisfied on every later offer.

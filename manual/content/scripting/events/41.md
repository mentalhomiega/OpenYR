type: event
id: TEVENT_FIRST_DAMAGED_ANY
title: First damaged (any source)
summary: Fires when damage lands on the tagged object while the object is at its maximum strength, with or without an attacker credited for it.
caveats:
  - Earlier damage does not matter. Any hit that lands while the object is at its type's maximum strength fires it, so an object repaired to full and hit again fires it again.
  - A hit that destroys an undamaged object in one blow also fires the event, before the destruction events.
  - A hit with an attacker credited for it offers the event twice. A volatile or semi-persistent tag is unaffected, because the first offer already fires the trigger or removes the tag from the object.
  - Repair and healing never fire the event.
  - An airborne aircraft that an [EM pulse](/systems/emp-pulse/) or an [ion storm](/systems/ion-storms/) brings down fires the event whatever its strength.
  - On a persistent tag, the event stays marked once satisfied, so the trigger fires on every later offer the tag receives, as [remembering a satisfied event](/systems/trigger-springing/#remembering-a-satisfied-event) describes. Those offers include the second offer of a credited hit and the other offers that follow in the same hit, so one hit can fire the trigger several times.

---
type: event
id: TEVENT_GAME_TIME
title: Elapsed Scenario Time...
summary: Satisfied once the given number of whole seconds has passed since the scenario began.
valid_values:
  - A number of seconds counted from the first frame of the scenario.
caveats:
  - A second is 15 game frames, so the count follows game speed. At a faster game speed the time passes sooner by the wall clock.
  - Nothing restarts the count. Unlike Elapsed Time..., the event is not affected by enabling the trigger or by a variable changing. Once the time has passed, it stays satisfied for the rest of the scenario.
  - The event is tested every frame, so a persistent tag fires every frame once the time has passed.
  - Give the trigger a volatile or a persistent tag. This event puts its tag only on the general list, which does not count toward the attachments a semi-persistent tag waits on. A semi-persistent tag therefore never fires unless an object or a map cell also holds it.
related:
  - type: system
    id: trigger-springing
  - type: event
    id: TEVENT_TIME
---

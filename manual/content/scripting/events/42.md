## The quarter health line usually takes the blow first

When one hit crosses both half strength and the [`ConditionRed`](/keys/conditionred/) line, only [Quarter health (any source)](/mapping/events/tevent-enter-red-any/) fires. How often this event can fire therefore depends on `ConditionRed`.

With `ConditionRed` at its default of `.5`, the red line sits at half strength, so almost every hit that crosses half strength also crosses the red line. This event then fires only for a hit that lands while the object is at exactly half its maximum strength, rounded down.

Any other `ConditionRed` value leaves a range of hits that fire this event:

- Below `.5`, the red line is under half strength. A hit fires this event when it starts at or above half strength and ends below half strength but not below the red line.
- Above `.5`, the red line is over half strength. A hit fires this event when it starts at or above half strength but not above the red line, however far below half it ends, provided the object survives.

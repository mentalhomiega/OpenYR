## What the exception covers

The exception covers every soldier that walks into its target structure, whether it captured the structure, restored it, spied on it or [did nothing at all](/systems/capture/#the-soldier-is-consumed). It also covers a soldier that takes a vehicle through the vehicle branch.

Which tag the change of owner offers this event to depends on how the soldier takes the object, because the soldier's [transferable](/systems/capture/#the-vehicle-branch) tag may already be on it:

| How the soldier takes the object | Tag offered this event on the change of owner |
| --- | --- |
| An engineer captures a structure | The engineer's tag if it is transferable, because it moves onto the structure before the owner changes. Otherwise the structure's own tag |
| A soldier takes a vehicle through the vehicle branch | The vehicle's own tag. The soldier's transferable tag moves onto the vehicle only after the owner changes |
| A `Thief=yes` soldier [steals a vehicle](/systems/capture/#stealing-a-vehicle) | The thief's tag if it is transferable, because it moves onto the vehicle first. Otherwise the vehicle's own tag |

A `Thief=yes` soldier is deleted after its theft without an offer of either event. So is a [`VehicleThief=yes`](/keys/vehiclethief/) soldier that the vehicle it is heading for runs over, which hands that vehicle to the soldier's house.

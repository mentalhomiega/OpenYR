---
type: action
id: TACTION_CLEAR_GLOBAL
title: Global Clear...
summary: Clears one of the scenario's fifty global variables.
valid_values:
  - A global variable number from 0 to 49. A number outside that range does nothing.
caveats:
  - Clearing a global that is already clear has no effect. Globals start each scenario clear, except those a [campaign carries over](/systems/campaign-progression/) from the previous mission.
  - Clearing a global that was set restarts the countdown of every trigger that has an `Elapsed Time...` or `Random delay...` event and a `Global is set...` or `Global is clear...` event naming that global.
  - Globals `0` and `1` also steer a campaign. A global `1` that is clear when a [`SkipMapSelect=yes`](/keys/skipmapselect/) mission is won sends the campaign to [`NextScenario`](/keys/nextscenario/), not [`AltNextScenario`](/keys/altnextscenario/). A global `0` that is clear when the mission is won opens the next mission's view at [`HomeCell`](/keys/homecell/), not [`AltHomeCell`](/keys/althomecell/). [Campaign progression](/systems/campaign-progression/#what-survives-the-boundary) covers both.
  - The `[VariableNames]` section of the rules labels globals by number. The label has no effect in the game, and the action always uses the number.

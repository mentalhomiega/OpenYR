caveats:
  - Give the particle system as its position in the rules' `[ParticleSystems]` list, counting from `0`. A name typed in that field selects the first system in the list. Keep the number inside the list; a number past its end can crash the game.
  - Whether anything appears depends on the chosen system's behavior, as the table below shows.
  - The system is not attached to anything, so it stays where it was placed until it ends or [Remove Particle Anim](/mapping/actions/taction-remove-particle-anim/) removes it.

## What each behavior does with no firer

A [particle system](/systems/particle-systems/) placed by this action has no firer and no target. Its `BehavesLike` value decides what appears.

| `BehavesLike` | Result |
| --- | --- |
| `Smoke` | Emits its particles and ends as it would anywhere else |
| `Spark` | Throws its bursts and ends when its spark frames run out, as it would anywhere else |
| `Fire` | Removes itself on its first update because it has no firer, so nothing is seen |
| `Gas`, `WeakGas`, `Web` | Starts with no particles and never creates any, so nothing is seen |
| `Railgun` | Draws its trail, and its beam if the type has one, from the waypoint toward cell `0,0` |
| Any other value | Does nothing, so nothing is seen |

---
type: action
id: TACTION_DELETE_OBJECT
title: Delete Attached Objects
summary: Takes every infantry, vehicle, aircraft and structure the trigger is attached to off the map without destroying it.
caveats:
  - No explosion plays, no kill is recorded, and none of the object's destruction trigger events fire.
  - Only an object on the map is removed. One carried inside a transport or otherwise in limbo is skipped.
related:
  - type: action
    id: TACTION_DESTROY_OBJECT
  - type: event
    id: TEVENT_DESTROYED
---

Every object whose tag holds this trigger is removed, not only the object that sprang it. Each one disappears the moment the action runs.

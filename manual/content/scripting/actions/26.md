---
type: action
id: TACTION_SUB_TIMER
title: Timer Shorten...
summary: Takes seconds off the mission countdown and sets it running; the count stops at zero.
valid_values:
  - A number of seconds of game time. Each second is 15 [frames](/glossary/#frame). A number at or above the time left takes the count to zero.
caveats:
  - The countdown runs afterwards even if it was stopped, so shortening a paused countdown also resumes it.
  - A count taken to zero expires the countdown as if it had run out. [Mission Timer Expired](/mapping/events/tevent-mission-timer-expired/) says when that event can be caught.
  - EVA says nothing. The clock jumps to the new count.
  - A reminder is spoken only when the count reads exactly one of the [reminder marks](/systems/sidebar/#the-credit-readout). A shortening that jumps past a mark skips that reminder.

---
type: action
id: TACTION_ZOOM_IN
title: Zoom in
summary: Magnifies the tactical view, hides the cursor, locks the mouse out of the map and stalls the game for a second.
caveats:
  - The magnified view is drawn before the stall starts. The stall lasts one second of real time, whatever the game speed. During it the game advances no frames, reads no input and handles no network traffic.
  - A band selection in progress is abandoned.
  - Zoom in keeps the mouse off the map without setting Lock input's lock. Zoom out and closing the options screen let the mouse back on the map unless Lock input's lock holds. Unlock input lets it back in either case.
  - Each Zoom in hides the cursor once more. After two in a row, one Zoom out restores the view but leaves the cursor hidden.

## What is killed

The action kills each infantry, vehicle, aircraft and structure that meets **all of:**

- it has strength left;
- it is on the map, not in [limbo](/glossary/#limbo), so passengers and objects inside a factory are skipped;
- it holds the tag that this trigger belongs to.

The damage uses [`C4Warhead`](/keys/c4warhead/), which chooses the death effects, such as the infantry death animation.

`Destroyed by anything` and `Destroyed by anything [not infiltrate]` spring on a victim's tag only when that tag did not fire this trigger, because a tag [ignores offers while it is being sprung](/systems/trigger-springing/#what-springing-does). Every victim holds the tag whose trigger is running. The destroyed events therefore spring on victims only when [Force Trigger](/mapping/actions/taction-force-trigger/), run by a trigger on a different tag, fired this trigger.

## The bridge

The action damages a bridge only when the offer that fired the trigger named a cell. It damages the bridge at that cell up to four times, and stops as soon as the span is destroyed. This happens even when [`DestroyableBridges=no`](/keys/destroyablebridges/).

The cell depends on the event that fired the trigger:

| Event | Cell |
| --- | --- |
| Cell entry | The tagged cell |
| A line crossing | The cell the infantry or vehicle entered, anywhere along the row or column |
| Zone entry | The destination of the infantry or vehicle, anywhere in the zone |
| Any other event, or [Force Trigger](/mapping/actions/taction-force-trigger/) | None, so no bridge is damaged |

:::danger[Attach this trigger only to objects that forced damage kills]
The action keeps damaging a tagged object until it has no strength left. An object that survives is damaged again at once, and the game hangs. It recovers only if a destroyed event removes the tag from the object, which is possible only when Force Trigger fired this trigger from a trigger on another tag.

These objects survive:

- a vehicle whose art sets [`DeathFrames`](/keys/deathframes/). It is set back to one point of strength to play its wreck animation, which cannot advance while the action runs;
- a [`BridgeRepairHut=yes`](/keys/bridgerepairhut/) structure whose type is also [`Immune=yes`](/keys/immune/);
- a firestorm wall section while its house's wall is raised. The damage [shortens how long the wall stays up](/systems/laser-fences/#damage-while-the-wall-is-up) instead;
- a harvester in a scenario that sets [`HarvesterImmune=yes`](/keys/harvesterimmune/), unless `C4Warhead` sets a positive [`LimpetFactor`](/keys/limpetfactor/);
- infantry without [`IsWebImmune=yes`](/keys/iswebimmune/), when `C4Warhead` sets [`Webby=yes`](/keys/webby/).

Any other object that survives forced damage hangs the game the same way.
:::

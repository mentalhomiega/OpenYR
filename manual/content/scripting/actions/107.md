---
type: action
id: TACTION_ENABLE_SHORT_GAME
title: Enable Short Game
summary: Turns the short game rule on, so a house in a skirmish or multiplayer game is defeated once it has no structures and no base unit left.
caveats:
  - The rule takes effect at once. A house that already has no structures and no base unit is defeated on the next game frame.
  - A defeated house loses everything it still has on the map, and every player is told of the defeat.
  - A campaign never applies the rule, so the action changes nothing there.
related:
  - type: action
    id: TACTION_DISABLE_SHORT_GAME
  - type: format
    id: spawn-ini
---

The base units are the vehicle types listed in [`BaseUnit`](/keys/baseunit/). A house of a [`MultiplayPassive=yes`](/keys/multiplaypassive/) country is never defeated this way.

The action overrides the short game option the match started with, for the rest of the match.

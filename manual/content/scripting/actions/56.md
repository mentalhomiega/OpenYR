---
type: action
id: TACTION_SET_LOCAL
title: Local Set...
summary: Sets one of the scenario's fifty local variables.
valid_values:
  - A local variable number from 0 to 49. A number outside that range does nothing.
caveats:
  - Setting a local that is already set changes nothing and restarts no countdown.
  - When the local changes from clear to set, every trigger with a [Local is set...](/mapping/events/tevent-local-set/) or [Local is clear...](/mapping/events/tevent-local-clear/) event naming that local restarts its elapsed time or random delay countdown. This applies to such triggers on every tag in the scenario.
  - A local can already be set when the scenario begins. The map may give it a starting value of 1. A local the map gives no starting value keeps the value that the previous mission, or an earlier attempt at this mission, left in it.
related:
  - type: action
    id: TACTION_CLEAR_LOCAL
  - type: event
    id: TEVENT_LOCAL_SET
  - type: event
    id: TEVENT_LOCAL_CLEAR
  - type: mission
    id: TMISSION_SET_LOCAL
  - type: action
    id: TACTION_SET_GLOBAL
  - type: system
    id: trigger-springing
---

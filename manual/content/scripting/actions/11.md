---
type: action
id: TACTION_TEXT_TRIGGER
title: Text Trigger...
summary: Prints one numbered line of tutorial text over the tactical view.
valid_values:
  - The number of a line in the map's `[Tutorial]` section or in `TUTORIAL.INI`.
caveats:
  - A number that neither holds prints nothing. The trigger's other actions still run.
  - Tutorial lines share the on-screen message list with chat and game notices. The list shows six messages, and each new message after that removes the oldest, so later messages can take the line off the screen before its time is up.
  - A line too wide for the message area is split into several messages. Each part plays the incoming-message sound and can be pushed off the screen separately.
related:
  - type: format
    id: tutorial-ini
  - type: key
    id: MessageDelay
---

The text comes from the numbered lines that [TUTORIAL.INI](/formats/tutorial-ini/) holds. A map can add or replace lines with a `[Tutorial]` section of its own. Its lines take precedence over `TUTORIAL.INI` lines with the same number for as long as the mission is played.

```ini title="TUTORIAL.INI"
[Tutorial]
120=Hold the ridge until the transports arrive.
```

```ini title="map file"
[Tutorial]
120=Hold the bridge instead.

[Actions]
DemoText=1,11,0,120,0,0,0,0, ; prints the map's line 120, "Hold the bridge instead."
```

The line stays on screen for [`MessageDelay`](/keys/messagedelay/) minutes unless later messages push it off.

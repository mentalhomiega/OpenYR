---
type: action
id: TACTION_UNLOCK_INPUT
title: Unlock input
summary: Brings the cursor back and lets the mouse reach the tactical view again.
caveats:
  - Key presses and clicks the game has not yet processed when the action runs are discarded.
  - The action runs whether or not input was locked. It makes no announcement either way.
  - The cursor comes back only if input was locked. Zoom in hides the cursor separately, without locking input. After a Zoom in, this action lets the mouse reach the map again, but the cursor stays hidden until Zoom out.
related:
  - type: action
    id: TACTION_LOCK_INPUT
  - type: action
    id: TACTION_ZOOM_OUT
---

---
type: action
id: TACTION_DISABLE_TRIGGER
title: Disable Trigger
summary: Stops every trigger of the named type from firing until Enable Trigger names it.
valid_values:
  - A trigger type the scenario declares. Each tag holding that type has its own trigger of the type, and the action disables all of them.
caveats:
  - A disabled trigger ignores its events and does not fire when Force Trigger names it. It stays on its tag and keeps the events it has already [marked](/systems/trigger-springing/#remembering-a-satisfied-event).
  - The countdown of an elapsed time or random delay event keeps running while the trigger is disabled, and can run out with no effect. Enable Trigger restarts the countdown from its full delay, so time spent disabled does not count toward it.

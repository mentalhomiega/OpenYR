---
type: action
id: TACTION_ENABLE_ALLY_REVEAL
title: Enable Ally Reveal
summary: Turns ally reveal on, so terrain that allied houses see is revealed for the local player too.
caveats:
  - The action changes the value `AllyReveal=` sets, and a saved game keeps the change. A later scenario in the same session keeps it only when neither a rules file nor the map sets `AllyReveal`. The standard rules.ini sets it, so each new scenario normally starts from the rules value.
related:
  - type: action
    id: TACTION_DISABLE_ALLY_REVEAL
  - type: key
    id: AllyReveal
  - type: system
    id: map-visibility
---

Turning ally reveal on uncovers nothing at that moment. An allied object reveals terrain for the local player the next time it reveals its surroundings, for example when it moves. [`AllyReveal`](/keys/allyreveal/) lists the moments when an ally's structures reveal their surroundings without moving.

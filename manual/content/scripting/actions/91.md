---
type: action
id: TACTION_GO_BERZERK
title: Go Berzerk
summary: Sends every infantry soldier whose tag is attached to this trigger berserk.
caveats:
  - Any infantry type can go berserk this way, whatever its health and whether or not it is a [`Cyborg=yes`](/keys/cyborg/) type.
  - The action affects every infantry soldier on the map whose tag is attached to this trigger, not only the one that sprang it. Infantry carried inside another object is skipped. Vehicles, aircraft and structures are never affected.
  - '[`BerzerkAllowed`](/keys/berzerkallowed/) does not affect this action. It controls only cyborgs that go berserk from damage.'
  - The action does not change the soldier's mission. A soldier on a mission that never looks for targets carries on as before. A cyborg that goes berserk from damage, by contrast, is also put on the guard-area mission.
related:
  - type: key
    id: BerzerkAllowed
  - type: key
    id: Cyborg
  - type: mission
    id: TMISSION_BERZERK
  - type: system
    id: target-selection
---

A berserk soldier attacks objects of its own house and its allies as well as enemies, because its [target search](/systems/target-selection/) no longer skips allied objects. It stays berserk for the rest of the scenario.

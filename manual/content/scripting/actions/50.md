---
type: action
id: TACTION_ZOOM_OUT
title: Zoom out
summary: Returns the tactical view to its ordinary size and brings the cursor back.
caveats:
  - The action releases the mouse lock set by Zoom in, but not a lock set by Lock input. While Lock input's lock holds, the map still ignores the mouse after this action.
  - Each Zoom out undoes one cursor hiding. It shows the cursor even when no Zoom in came before it, including while Lock input's lock holds.
  - Key presses and clicks the game has not yet processed when the action runs are discarded.

---
type: action
id: TACTION_FORCE_TRIGGER
title: Force Trigger
summary: Fires every trigger of the named type at once, without checking its events.
valid_values:
  - A trigger type the scenario declares. Each tag that carries the type holds its own trigger of that type, and every one of them fires.
caveats:
  - A disabled trigger, or one already marked for destruction, does not fire.
  - The trigger fires without going through its tag, so a tag that is already springing does not stop it.
related:

    id: TACTION_ENABLE_TRIGGER

---

[Reaching a trigger from another trigger](/systems/trigger-springing/#reaching-a-trigger-from-another-trigger) covers what forcing skips and what it leaves behind.

:::caution[Do not force a trigger's own type from inside it]
A trigger whose actions force its own trigger type crashes the game. The forced trigger runs its whole action list again, including the Force Trigger action, which forces it again, one level deeper each time. A tag cannot spring while it is already springing, but forcing skips the tag, so nothing stops the repetition until the game runs out of stack. Two trigger types that force each other crash the same way. Disabling or destroying the forced type earlier in the same action list prevents the crash, because a disabled or destroyed trigger is not forced.
:::

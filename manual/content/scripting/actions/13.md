---
type: action
id: TACTION_AUTOCREATE
title: Autocreate Begins...
summary: Marks the given house as alerted, a state that changes nothing in play.
valid_values:
  - A house available to the scenario.
caveats:
  - No team is created, and no house builds anything it would not have built without the action.
related:
  - type: key
    id: Production
  - type: key
    id: Autocreate
  - type: key
    id: AutocreateTime
  - type: system
    id: ai-team-production
---

A house raises teams from its AI triggers only while [its AI-trigger switch is on and its ratio roll succeeds](/systems/ai-team-production/#when-the-pass-runs). This action changes neither.

The TeamType setting [`Autocreate`](/keys/autocreate/) shares the name but is unrelated, and this action does not change it.

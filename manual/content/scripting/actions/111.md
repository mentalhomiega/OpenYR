---
type: action
id: TACTION_MAKE_ELITE
title: Make Elite
summary: Promotes to elite every infantry, vehicle, aircraft and structure the trigger is attached to.
caveats:
  - Only an object on the map is promoted. One carried inside a transport or otherwise in limbo is skipped.
related:
  - type: action
    id: TACTION_DELETE_OBJECT
---

Every object whose tag holds this trigger is promoted, not only the object that sprang it.

The object gets the same elite rank that kills earn, with the same elite weapon, [`EliteAbilities`](/keys/eliteabilities/) and insignia. The promotion ignores [`Trainable`](/keys/trainable/) and [`VeteranCap`](/keys/veterancap/). [Promotion without kills](/systems/veterancy/#promotion-without-kills) compares it with the other ways to give an object a rank.

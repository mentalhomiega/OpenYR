---
type: action
id: TACTION_TURN_ON_ATTACHED
title: Turn on building
summary: Puts every switched-off structure whose tag is attached to this trigger back into service.
caveats:
  - Every structure in the scenario whose tag is attached to this trigger is switched on, not only the structure that sprang it. A structure in limbo, or one not yet placed on the map, is skipped.
  - Only a structure that has been switched off is affected. A structure that is running below capacity because its house is short of power is still switched on, so the action leaves it and the shortage unchanged.
  - A switched-off structure that is stunned, for example by an [EM pulse](/systems/emp-pulse/), stays off.
  - A house under player control hears the structure-online announcement. Several structures switched on by one firing produce one announcement.
related:

    id: power

    id: Powered

    id: emp-pulse

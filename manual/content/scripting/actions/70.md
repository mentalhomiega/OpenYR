## The disposal that clears a held victory

Destroy Tag is the dependable way to lift an [allow-win](/mapping/actions/taction-allowwin/#destroying-the-tag-instead) hold. The tag is removed with its triggers still attached, so the hold is lifted whatever [lifetime](/systems/trigger-springing/#tag-lifetimes) the tag had and however many triggers it held.

The hold stays in two cases:

- [Destroy Trigger](/mapping/actions/taction-destroy-trigger/) has already removed the tag's triggers.
- Springing has already removed the tag, so there is no tag of that type left to name.

Removing an allow-win tag with a trigger still attached also restarts a house's result countdown, so a win flagged for that house in the same frame waits for the countdown. [Allow Win](/mapping/actions/taction-allowwin/#what-brings-the-count-back-down) gives the count, the house whose countdown restarts, and the countdown's length.

---
type: action
id: TACTION_ENABLE_TRIGGER
title: Enable Trigger
summary: Enables every trigger of the named type and restarts the countdown behind its timed events.
valid_values:
  - A trigger type the scenario declares. Each tag holding that type has its own trigger of the type, and the action enables all of them.
caveats:
  - Enabling restarts the trigger's countdown. An elapsed time or random delay event on the trigger counts its full delay again from the moment this action runs, and a random delay is drawn again.
  - The countdown restarts even if the trigger was already enabled, so running the action again restarts a countdown already in progress.
  - Nothing else about the trigger is reset. Events already [marked](/systems/trigger-springing/#remembering-a-satisfied-event) stay marked. A trigger with no elapsed time or random delay event is only switched on.
  - A trigger waiting to be deleted, for example by Destroy Trigger, is enabled but never fires.
  - The action does nothing to a trigger switched off for the difficulty being played. It cannot bring such a trigger back.

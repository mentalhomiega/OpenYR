---
type: action
id: TACTION_DISABLE_SPEECH
title: Disable Speech
summary: Stops EVA's announcements until speech is enabled again; other speech lines still play.
caveats:
  - Only EVA lines, those whose file names start with `00-` or `01-`, are blocked. The block applies whatever asks for the line, Play Speech included. Every other line still plays.
  - Lines already speaking or waiting in the speech queue still play. Only lines requested afterward are blocked.
  - The block lasts until Enable Speech runs or the next scenario starts. A saved game keeps it.
  - The block covers the whole game, not one house, so every player stops hearing EVA.
related:
  - type: action
    id: TACTION_ENABLE_SPEECH
  - type: action
    id: TACTION_PLAY_SPEECH
---

[EVA speech](/systems/eva-speech/#turning-eva-off) describes the speech queue and which lines count as EVA's.

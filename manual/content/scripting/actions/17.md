---
type: action
id: TACTION_REVEAL_SOME
title: Reveal around waypoint...
summary: Uncovers the ground within RevealTriggerRadius cells of a waypoint for every human player.
valid_values:
  - A scenario waypoint, read from the number field of the action line. The waypoint label at the end of the line is not used.
caveats:
  - A line whose number field is `0` reveals around waypoint `0`, whatever label ends the line. If the scenario places no waypoint `0`, the reveal is centered on a cell outside the playfield and uncovers nothing.
  - The action does nothing for a player whose map is already marked as fully revealed by Reveal all map, the reveal team mission or the reveal crate. Reshrouding the map clears the mark.
related:
  - type: key
    id: RevealTriggerRadius
  - type: system
    id: map-visibility
  - type: action
    id: TACTION_REVEAL_ALL
  - type: action
    id: TACTION_REVEAL_ZONE
---

```ini title="map file"
[Actions]
DemoReveal=1,17,0,9,0,0,0,0,J ; trigger DemoReveal uncovers the ground around waypoint 9, whose label is J
```

The number `9` is the waypoint the action reveals around, and `J` is its label.

The reveal lifts both the shroud and the fog, and the [height test](/keys/revealbyheight/) applies, so high ground can block part of it. [Map visibility](/systems/map-visibility/#reveals-granted-outright) compares this reveal with the others.

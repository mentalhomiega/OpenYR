---
type: action
id: TACTION_WAKEUP_SELF
title: Wakeup self
summary: Puts every sleeping or harmless infantry, vehicle and aircraft that carries this trigger's tag on guard.
caveats:
  - Every object carrying the tag is woken, not only the one that sprang the trigger. Map objects given the same tag [share one tag](/systems/trigger-springing/#tags-triggers-and-events-in-brief), so a tag given to twelve objects wakes all twelve. Each team has a separate copy of its TeamType's tag, so one team's trigger wakes only that team's members.
  - Structures are skipped whatever mission they are on.
  - Only the Sleep and Harmless missions change to Guard. An object on any other mission keeps it.
  - Objects that are not on the map, such as passengers inside a transport, are skipped.
  - The objects are found through the trigger, so the action works however the trigger fired, including from a cell or through the Force Trigger action.

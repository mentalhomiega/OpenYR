---
type: action
id: TACTION_ADD_TIMER
title: Timer Extend...
summary: Adds seconds to the mission countdown and sets it running.
valid_values:
  - A number of seconds of game time. Each second is 15 [frames](/glossary/#frame).
caveats:
  - The new count is the time left plus the seconds added. The countdown runs afterwards even if it was stopped, so extending a paused countdown also resumes it.
  - EVA says nothing. The clock jumps to the new count.
  - A reminder is spoken only when the count reads exactly one of the [reminder marks](/systems/sidebar/#the-credit-readout). An extension that jumps past a mark skips that reminder.

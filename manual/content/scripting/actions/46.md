---
type: action
id: TACTION_LOCK_INPUT
title: Lock input
summary: Hides the cursor and stops the mouse reaching the tactical view until Unlock input runs.
caveats:
  - The lock covers only the mouse over the tactical view. Clicks on the map are ignored, and the mouse no longer scrolls the map. Keyboard commands and sidebar buttons still respond, so a player who knows the layout can still act with the cursor hidden.
  - Quick save and quick load are refused while the lock holds.
  - As the lock goes on, a band selection in progress is abandoned, structure placement is canceled, and the repair, sell, power and waypoint modes are switched off. Control comes back with the ordinary cursor, whatever mode the player was in.
  - EVA announces that control has been taken each time the action runs, even when input is already locked. Running the action twice still needs only one Unlock input to release the lock.
  - Within the mission, only Unlock input releases the lock. The lock is still in force after the options screen closes, and a game saved during the lock is locked again when loaded. The lock does not carry over into the next mission.
  - Zoom out with no Zoom in before it shows the cursor even while the lock holds. The map still ignores the mouse.
related:

    id: TACTION_UNLOCK_INPUT

    id: TACTION_ZOOM_IN
  - type: system
    id: trigger-springing

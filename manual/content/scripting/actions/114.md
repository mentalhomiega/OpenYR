---
type: action
id: TACTION_CREATE_AUTOSAVE
title: Create Autosave
summary: Saves the game once the current frame has finished.
caveats:
  - A campaign or skirmish save goes into the same rotating slots as timed autosaves. A multiplayer game writes its next numbered multiplayer save, and writes nothing once a player has left the match.
  - A successful save restarts the countdown to the next timed autosave.
related:
  - type: format
    id: save-games
  - type: using
    id: compatibility-and-saves
---

The save is written after everything removed during the frame has been released, so an object that [Delete Attached Objects](/mapping/actions/taction-delete-object/) removes anywhere in the same frame is not in the save. [Automatic saves](/formats/save-games/#automatic-saves) lists the file names and descriptions. [When the file is written](/formats/save-games/#when-the-file-is-written) covers saves requested while timed saves are off or a recording plays back, several requests in one frame, and what the message list shows.

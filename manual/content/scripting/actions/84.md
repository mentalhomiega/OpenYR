---
type: action
id: TACTION_WAKEUP_GROUP
title: Wakeup group...
summary: Puts every sleeping or harmless infantry, vehicle and aircraft in one numbered group on guard.
valid_values:
  - A group number. Objects start in group `-1`. A placed object's [map row](/formats/scenario-objects/) can set its group, and so can the Set Group ID action. A team puts each member in its TeamType's [`Group`](/keys/group/#scope-teamtype) as the member joins. The player's control groups are numbered from `0`, so the first control group is group `0`.
caveats:
  - The number is matched exactly. `0` wakes the player's first control group, and `-1` wakes every object that has no group.
  - Structures are skipped.
  - Only the Sleep and Harmless missions change to Guard.
  - Destroyed objects and objects that are not on the map, such as passengers inside a transport, are skipped.
  - Objects of every house are woken.
related:

    id: MissionType
  - type: action
    id: TACTION_SET_GROUP_ID
  - type: action
    id: TACTION_WAKEUP_SELF
  - type: key
    id: Group
    scope: teamtype

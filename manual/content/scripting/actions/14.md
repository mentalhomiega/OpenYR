---
type: action
id: TACTION_CHANGE_HOUSE
title: Change House
summary: Hands every infantry, vehicle, aircraft and structure the trigger is attached to over to the given house.
valid_values:
  - A house available to the scenario.
caveats:
  - Every object whose tag holds this trigger changes hands, not only the object that sprang it. One firing can transfer several objects.
  - Only an object on the map changes hands. One carried inside a transport or otherwise in limbo is skipped.
  - The action does nothing when the given house is a country nobody plays or a spawn house nobody holds.
related:
  - type: action
    id: TACTION_ALL_CHANGE_HOUSE
---

## Behavior

Each object changes owner the way a mind control transfer does, so it springs no entered trigger. [Taking an object over](/systems/mind-control/#taking-an-object-over) lists the effects, and [what changes hands](/systems/capture/#what-changes-hands) lists the steps a structure's bookkeeping goes through. Outside a campaign, a computer house that receives a structure sells it.

The action finds the objects by their tags, so it can fire from any event. If no object carries a tag holding this trigger, it transfers nothing.

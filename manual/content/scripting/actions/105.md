---
type: action
id: TACTION_TALK_BUBBLE
title: Talk Bubble...
summary: Takes down the talk bubble, or puts one over a team member when the line gives a bubble style.
caveats:
  - When the line names a team, the action works only while a team of that type is on the map. A TeamType with no live team leaves the action doing nothing. A team with no members takes the bubble down.
  - A line that names no team takes the bubble down.
related:
  - type: mission
    id: TMISSION_TALK_BUBBLE
  - type: enum
    id: TalkType
  - type: key
    id: TalkBubbleTime
---

The usual line uses [parameter code](/formats/scenario-triggers/#the-action-row) `1`, which carries no bubble style. The style is then `0`, so the action only takes the bubble down:

```ini title="map file"
[Actions]
; 01000020-G is a TeamType the map defines
Quiet=1,105,1,01000020-G,0,0,0,0,
```

To put a bubble up, write parameter code `4` and a [talk bubble](/reference/enums/talk-bubble/) style in the last field. The bubble appears over one member of the first live team of that type, the member that team took on most recently:

```ini title="map file"
[Actions]
Ask=1,105,4,01000020-G,0,0,0,0,2 ; question-mark bubble
```

[`TalkBubbleTime`](/keys/talkbubbletime/) covers how long a bubble stays up and what else placing one does. The [Talk Bubble](/mapping/missions/tmission-talk-bubble/) team mission also puts a bubble up.

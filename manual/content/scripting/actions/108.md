---
type: action
id: TACTION_DISABLE_SHORT_GAME
title: Disable Short Game
summary: Turns the short game rule off, so a house in a skirmish or multiplayer game is defeated only once it has no structures, aircraft, infantry or vehicles left.
caveats:
  - During a harvester truce, harvesters do not count as vehicles. A house left with nothing but harvesters is defeated.
  - A defeated house loses everything it still has on the map, and every player is told of the defeat.
  - A campaign never applies the rule, so the action changes nothing there.
related:
  - type: action
    id: TACTION_ENABLE_SHORT_GAME
  - type: format
    id: spawn-ini
---

[`HarvesterImmune`](/keys/harvesterimmune/) describes the harvester truce, and the harvesters are the vehicle types listed in [`HarvesterUnit`](/keys/harvesterunit/). A house of a [`MultiplayPassive=yes`](/keys/multiplaypassive/) country is never defeated this way.

The action overrides the short game option the match started with, for the rest of the match.

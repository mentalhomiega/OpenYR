---
type: action
id: TACTION_SET_AMBIENT_RATE
title: Set ambient rate...
summary: Replaces AmbientChangeRate, the number of minutes between ambient light fade steps, with a value taken from the number's bit pattern.
valid_values:
  - A whole number whose bits are read as a single-precision floating-point rate in minutes. To set a rate, write the whole number with that rate's bit pattern, such as `1045220557` for `0.2` or `1065353216` for `1`.
caveats:
  - A decimal such as `.2` is read as the whole number `0` and sets the rate to `0`. The ambient light then stays at its current level until another rate is set.
  - A small whole number such as `5` sets a rate barely above `0`, so the fade takes a step on every frame.
  - The new rate applies to every ambient fade, including an ion storm's darkening and recovery.
  - A saved game keeps the new rate, and it can carry into later scenarios; see [`AmbientChangeRate`](/keys/ambientchangerate/).

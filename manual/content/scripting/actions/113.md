---
type: action
id: TACTION_DISABLE_ALLY_REVEAL
title: Disable Ally Reveal
summary: Turns ally reveal off, so terrain that allied houses see is no longer revealed for the local player.
caveats:
  - The action changes the value `AllyReveal=` sets, and a saved game keeps the change. A later scenario in the same session keeps it only when neither a rules file nor the map sets `AllyReveal`. The standard rules.ini sets it, so each new scenario normally starts from the rules value.
  - The action does not shroud terrain that allies have already revealed. Only what they see from now on is withheld.
related:

    id: TACTION_ENABLE_ALLY_REVEAL
  - type: key
    id: AllyReveal
  - type: system
    id: map-visibility

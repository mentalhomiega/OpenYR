---
type: action
id: TACTION_SET_TIMER
title: Timer Set...
summary: Sets the mission countdown to the number of seconds given, starts it running, and EVA announces it.
valid_values:
  - A number of seconds of game time. Each second is 15 [frames](/glossary/#frame).
caveats:
  - The countdown runs afterwards whatever state it was in, so no Timer Start action is needed.
  - EVA announces the countdown on every firing, including one that resets a countdown already running, unless that announcement is already speaking or waiting.
  - A count of `0` expires the countdown at once, as if it had run out. [Mission Timer Expired](/mapping/events/tevent-mission-timer-expired/) says when that event can be caught.
related:

    id: TACTION_START_TIMER

    id: TACTION_ADD_TIMER

    id: TACTION_SUB_TIMER

    id: TEVENT_MISSION_TIMER_EXPIRED

---
type: action
id: TACTION_CLEAR_LOCAL
title: Local Clear...
summary: Clears one of the scenario's fifty local variables.
valid_values:
  - A local variable number from 0 to 49. A number outside that range does nothing.
caveats:
  - Clearing a local that is already clear changes nothing, so it restarts no countdown.
  - Clearing a local that was set restarts the elapsed-time and random-delay countdowns of every trigger that has an event naming that local, wherever the trigger is attached.
  - Locals are not reset between scenarios. A local the map gives no starting state keeps whatever the previous mission left in it, so clearing it at the start of a later mission can be a real change.
related:
  - type: action
    id: TACTION_SET_LOCAL
  - type: event
    id: TEVENT_LOCAL_CLEAR
  - type: event
    id: TEVENT_LOCAL_SET
  - type: mission
    id: TMISSION_CLEAR_LOCAL
  - type: action
    id: TACTION_CLEAR_GLOBAL
  - type: system
    id: trigger-springing
---

---
type: action
id: TACTION_START_TIMER
title: Timer Start
summary: Resumes the mission countdown from the count it was stopped at, and EVA announces it.
caveats:
  - The action does nothing while the countdown is already running.
  - The count is resumed, not set. Starting a countdown whose count is zero, because no action has set it or because it has already run out, expires it at once. [Mission Timer Expired](/mapping/events/tevent-mission-timer-expired/) says when that event can be caught.
  - The clock appears beside the [credit readout](/systems/sidebar/#the-credit-readout) only while the countdown is running.

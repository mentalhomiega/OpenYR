---
command_id: PerfOverlay
---

Shows the performance overlay over the top left of the map view, at its `Basic` level, then at its `Detailed` level, then hides it again. The overlay shows only during a game and not while a menu is open. Each press changes the [`PerfOverlay=`](/keys/perfoverlay/) setting, so the next save of the settings keeps the level.

The command is on Ctrl+Shift+P in both control schemes unless [`KEYBOARDMD.INI`](/formats/keyboard-ini/) binds it to another key. A keyboard file saved before this command existed gains that key when it names no other command on it and no other command holds the key.

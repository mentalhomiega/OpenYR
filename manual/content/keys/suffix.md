---
key: Suffix
summary: A theater's artwork file extension; on a country, a value the engine never uses.
---

On a [theater](/keys/suffix/#scope-theater), the value is the extension of the theater's artwork files, written without the dot. It also names theater files such as `DES.MIX`, `ISODES.PAL` and `UNITDES.PAL` when the value is `DES`. On a [country](/keys/suffix/#scope-housetype), the value is stored and never used.

key: ShowFPS
scope: client-settings
label: Show FPS
when_omitted:
  kind: value
  value: "no"
---

`ShowFPS=yes` draws a frame count in the top-left corner of the game view. The count is the number of game frames the game ran in the last second. It follows the game speed, and it does not count the pictures drawn between game frames, so it is not the picture rate of the display.

The count appears only during a game. The menus do not show it.

The **Show FPS** switch on the Display page of the settings sets the key, and the change applies at once.

`SuperLowPowerGarrisoned=` names the animation the super low power slot is meant to run in place of [`SuperLowPower`](/keys/superlowpower/) while infantry occupy the structure. No structure can be occupied yet, so the value is read but never used. [The damaged form](/systems/building-animations/#the-damaged-form) covers the slot's three names.

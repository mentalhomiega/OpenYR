label: Own armor multiplier
when_omitted:
  kind: value
  value: "1.0"
  note: "Damage taken is unchanged."
---

`AttachEffect.ArmorMultiplier` divides the damage an object of this type takes while its [own effect](/systems/attach-effects/#an-object-types-own-effect) lasts, in the same way as a [warhead's armor multiplier](/keys/attacheffect.armormultiplier/#scope-warheadtype).

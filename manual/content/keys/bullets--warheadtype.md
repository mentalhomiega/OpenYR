---
key: Bullets
scope: warheadtype
label: Warhead bullets flag
when_omitted:
  kind: value
  value: "no"
no_effect: true
---

`Bullets=yes` is read from a warhead section and stored. Nothing in the game tests it, so a warhead behaves the same with either value, including the small-arms warheads of the stock rules that set it.

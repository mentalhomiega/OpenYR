`MultiEngineer` sets the starting state of the Multi Engineer option on the skirmish setup screen. The screen shows this value until a match starts from it. With the option on, an engineer that enters a structure above its condition-red health damages the structure instead of capturing it, outside a campaign. A structure of a multiplayer-passive house is left alone. [Engineers, capture and sabotage](/systems/capture/) describes capture.

`ActiveAnimFourGarrisoned=` names the animation active slot four is meant to run in place of [`ActiveAnimFour`](/keys/activeanimfour/) while infantry occupy the structure. No structure can be occupied yet, so the value is read but never used. [The damaged form](/systems/building-animations/#the-damaged-form) covers the slot's three names.

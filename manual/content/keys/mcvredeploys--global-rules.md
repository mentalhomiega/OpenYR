when_omitted:
  kind: value
  value: "yes"
  note: The stock rules set `yes`.
---

`MCVRedeploys` sets the starting state of the Re-Deployable MCV option on the skirmish setup screen. The screen shows this value until a match starts from it. With the option on, a human player can move a construction yard in a skirmish or multiplayer match, which redeploys it. With the option off, a construction yard cannot be moved in those matches.

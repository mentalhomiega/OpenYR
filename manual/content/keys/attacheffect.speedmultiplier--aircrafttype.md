key: AttachEffect.SpeedMultiplier
scope: aircrafttype
label: Own speed multiplier
when_omitted:
  kind: value
  value: "1.0"
  note: "Speed is unchanged."
---

`AttachEffect.SpeedMultiplier` multiplies the movement speed of an object of this type while its [own effect](/systems/attach-effects/#an-object-types-own-effect) lasts, in the same way as a [warhead's speed multiplier](/keys/attacheffect.speedmultiplier/#scope-warheadtype).

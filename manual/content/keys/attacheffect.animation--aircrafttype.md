`AttachEffect.Animation` names the animation shown on an object of this type while its [own effect](/systems/attach-effects/#an-object-types-own-effect) lasts. It follows the same rules as a [warhead's effect animation](/keys/attacheffect.animation/#scope-warheadtype).

`SpecialAnimGarrisoned=` names the animation special slot one is meant to run in place of [`SpecialAnim`](/keys/specialanim/) while infantry occupy the structure. No structure can be occupied yet, so the value is read but never used. [The damaged form](/systems/building-animations/#the-damaged-form) covers the slot's three names.

---
key: ToSnowTheater
summary: Parsed tile-set number that the engine stores and never reads.
no_effect: true
see_also: [ToTemperateTheater]
when_omitted:
  kind: value
  value: "-1"
---

The name describes the tile set that would replace this one when a map is converted to the snow theater. OpenTS performs no such conversion and never reads the value, so it affects neither the game nor multiplayer synchronization.

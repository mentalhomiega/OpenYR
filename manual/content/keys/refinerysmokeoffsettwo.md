---
key: RefinerySmokeOffsetTwo
summary: Where the second smoke system of a harvester's payout starts, relative to the structure.
see_also: [RefinerySmokeOffsetOne, RefinerySmokeParticleSystem]
when_omitted:
  kind: value
  value: 0,0,0
---

This is the second position at which [`RefinerySmokeParticleSystem`](/keys/refinerysmokeparticlesystem/) starts a system on each payout. It is read and used as [`RefinerySmokeOffsetOne`](/keys/refinerysmokeoffsetone/) is, and a payout starts a system here only when it is set.

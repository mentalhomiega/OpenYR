title: EMEffect has no pulse in Ares rules
category: feature

targets:
- type: key
  id: EMEffectPulse
  effect: added
credit: [MentalHomiega]

`EMEffectPulse=` decides whether `EMEffect=yes` without `EMP.Duration=` makes the stock stunning pulse. Rules that declare Ares armor types get no pulse by default, as in Ares; stock rules keep it.

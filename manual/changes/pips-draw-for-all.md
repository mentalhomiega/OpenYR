---
title: Show an object's pips to everyone with PipsDrawForAll
category: feature
release: 0.2.0
targets:
- type: key
  id: PipsDrawForAll
  effect: added
credit:
- MentalHomiega
---

A type can set `PipsDrawForAll=yes` to show its objects' pips to every player, not only the owner's allies, as the Psychic Sensor does in Yuri's Revenge.

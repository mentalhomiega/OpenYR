---
title: Give any soldier the Desolator's deploy aim (IsDesolator)
category: feature
release: 0.2.0
targets:
- type: key
  id: IsDesolator
  effect: added
credit: [MentalHomiega]
---

A soldier type can now set `IsDesolator`, as Ares does, so its AreaFire deploy weapon does not aim at its own cell. It defaults to yes for the type named `DESO` and no for others, so stock rules are unchanged.

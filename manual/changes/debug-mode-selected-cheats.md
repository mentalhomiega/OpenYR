With [Debug mode](/keys/debugmode/) on, four more commands join the Debug category. Heal Selected restores full strength to the selected units and buildings, Promote Selected makes the selected trainable units elite, and Destroy Selected destroys the selected units and buildings. Each runs once. Fast-Forward is a toggle that runs the game without the frame limit of the game speed.

---
title: Give an AG=no structure no attack cursor over an airborne object
category: fix
release: 0.2.0
targets:
- type: key
  id: AG
  effect: changed
credit:
- MentalHomiega
---

A structure whose first weapon slot is [`AG=no`](/keys/ag/) no longer gets the attack cursor over an airborne object. Before, an [`AA=yes`](/keys/aa/) first slot offered the cursor against aircraft, such as an aircraft over the SAM site `NASAM`. Automatic fire at aircraft is unchanged.

title: Space out animation damage with Damage.Delay
category: feature
release: 0.2.0
targets:
- type: key
  id: Damage.Delay
  effect: added
credit:
- MentalHomiega
---

`Damage.Delay=` in an animation section applies the animation's `Damage` only on every that many animation frames. The default `0` applies it on every frame.

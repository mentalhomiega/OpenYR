title: Add FastestGpu to draw on the fastest graphics card
category: feature
release: 0.2.0
targets:
- type: key
  id: FastestGpu
  effect: added
credit:
- MentalHomiega
---

[`FastestGpu`](/keys/fastestgpu/) draws the game on the graphics card Windows ranks fastest. It is on by default, so a computer with two graphics cards that drew on the slower one now draws on the faster one; `FastestGpu=no` keeps the first card Windows lists.

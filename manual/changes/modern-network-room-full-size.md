With the modern [menu style](/keys/menustyle/), the network and CnCNet game room is now as big as the skirmish lobby. The players, the chat and the line to type in fill the left column; the map, the game settings and the switches fill the right. The host's boot button is now a labelled Kick Player button, which kicks the player picked in the list. The classic style keeps the original 640 by 391 room.

---
title: Set the size of a warhead's light flash (CombatLightSize)
category: feature
release: 0.2.0
targets:
- type: key
  id: CombatLightSize
  effect: added
credit: [MentalHomiega]

A bright warhead can now give its light flash a fixed share of the largest size with `CombatLightSize`, as Ares does. With the key left out the damage sets the size as before.

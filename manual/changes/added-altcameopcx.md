title: Draw the alternate sidebar cameo from a PCX file
category: feature

targets:
- type: key
  id: AltCameoPCX
  effect: added
credit:
- MentalHomiega
---

`AltCameoPCX=` in an object's image section of `art.ini` names the PCX picture drawn as its sidebar cameo while the alternate cameo is shown, as `CameoPCX=` does for the normal cameo.

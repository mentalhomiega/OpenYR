title: Make the modern build panel's background translucent
category: feature
release: 0.2.0
targets:
- type: key
  id: SidebarOpacity
  effect: added
credit: [MentalHomiega]
---

The modern build panel's background now lets the map show through. [`SidebarOpacity`](/keys/sidebaropacity/) sets how solid it is, from 0 to 100 percent, and the default is 80. The radar, the buttons, the cameos, the tab icons and the text stay opaque. The Graphics page of the settings has a Sidebar opacity slider in its Interface section. The classic sidebar is unchanged.

---
title: Let a designator or aircraft type set the airstrike call voice (VoiceAirstrikeAttack)
category: feature
release: 0.2.0
targets:
- type: key
  id: VoiceAirstrikeAttack
  effect: added
credit: [MentalHomiega]
---

An airstrike called by the player now plays the designator's `VoiceAirstrikeAttack`, or the aircraft type's, in place of `[AudioVisual] AirstrikeAttackVoice`, as Ares does. Types that leave the key out are unchanged.

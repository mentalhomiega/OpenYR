---
title: Choose a mod's game modes and game options in the skirmish lobby
category: feature
release: 0.2.0
targets: []
credit: [MentalHomiega]
---

A mod that declares game modes and game options in the CnCNet client's files, named in [`mod.ini`](/formats/mod-ini/#game-modes-and-game-options), gets a game mode list and its options in the skirmish lobby. The map list shows the maps of the chosen mode, an option the mode or the map sets is greyed with a note that says which, and the match applies the mode's and the options' rules overlays. [`TeamRetaliate`](/keys/teamretaliate/), [`AllowParallelAIQueues`](/keys/allowparallelaiqueues/) and [`AllowBypassBuildLimit`](/keys/allowbypassbuildlimit/) are read.

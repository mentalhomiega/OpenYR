[`RMGVegetationMapType`](/keys/rmgvegetationmaptype/) picks which map type's entry of the `RMGMD.INI` vegetation lists the randomize button uses. The generator has no Yuri's Revenge map types, so the key stands in for the dialog's map type choice and defaults to continent.

A Cooperative match now allies every person with every other person, and every computer player with every other computer player, as Yuri's Revenge does. Before, houses were allied only as the launch file's seats said, so two people in a launch file with no ally masks fought each other. See [the multiplayer mode](/formats/spawn-ini/#the-multiplayer-mode).

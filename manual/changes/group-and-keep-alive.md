In rulesmd.ini, `GroupAs=` on a type makes the Select Same Type command treat every type with the same text as one kind. `KeepAlive=yes` on a type keeps a player in a short game while they own an object of it, and `KeepAlive=no` stops a structure from doing so. Both keys follow the Ares documentation.

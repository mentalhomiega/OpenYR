---
title: Let an aircraft crash without spinning (CrashSpin)
category: feature
release: 0.2.0
targets:
- type: key
  id: CrashSpin
  effect: added
credit: [MentalHomiega]
---

An aircraft type with `CrashSpin=no` now falls without rolling or pitching when it is shot down, as Ares does. Aircraft that leave the key out still spin.

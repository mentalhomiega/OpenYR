---
title: Let a healer deploy by clicking itself (NoSelfGuardArea)
category: feature
release: 0.2.0
targets:
- type: key
  id: NoSelfGuardArea
  effect: added
credit: [MentalHomiega]
---

A soldier type with a healing weapon and `NoSelfGuardArea=yes` no longer gets the guard area cursor over itself, so a healer that can deploy shows the deploy cursor, as Ares does. Healers that leave the key out are unchanged.

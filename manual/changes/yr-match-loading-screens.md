A skirmish or multiplayer match now loads behind the local player's country picture, with the country's name, special unit and description, the map's preview marked with each house's start position, and a row for each player with a bar, flag and name in the player's color. It used to show a Tiberian Sun picture with plain bars. A country past the tenth in `[Countries]` still gets the older screen.

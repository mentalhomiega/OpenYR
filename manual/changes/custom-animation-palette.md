title: Draw an animation with its own palette

  id: CustomPalette
  effect: added
credit:

An animation's section in artmd.ini can set `CustomPalette` to a palette file, so the animation is drawn in that file's colors. Three tildes in the name become the current theater's suffix. The key follows the Ares documentation.

---
title: Toggle beacon placement from the sidebar's beacon button
category: feature
release: 0.2.0
targets:
- type: system
  id: sidebar
  effect: changed
credit: [MentalHomiega]
---

The beacon button on the modern panel turns beacon placement on and off, as the `PlaceBeacon` command does. In a multiplayer game the next map click places a beacon. In a single-player or skirmish game the button does nothing, as in Yuri's Revenge. The button shows as on while the mode is on, and its tooltip no longer says "Coming soon". The power down button still says "Coming soon".

---
title: Let rules turn off power mode (TogglePowerAllowed)
category: feature
release: 0.2.0
targets:
- type: key
  id: TogglePowerAllowed
  effect: added
credit: [MentalHomiega]
---

With `[General]` `TogglePowerAllowed=no`, the Power Mode command and the sidebar power button now do nothing, as in Ares. Rules that leave the key out keep power mode.

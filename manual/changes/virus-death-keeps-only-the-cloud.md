A [`NotHuman=yes`](/keys/nothuman/) soldier or a parachuting soldier killed by an [`InfDeath=8`](/keys/infdeath/) warhead no longer leaves the [`InfantryVirus`](/keys/infantryvirus/) animation. Only the animation's poison cloud remains, as in Yuri's Revenge.

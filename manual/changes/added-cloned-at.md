---
title: Copy a unit at listed structures (ClonedAt)
category: feature
release: 0.2.0
targets:
- type: key
  id: ClonedAt
  effect: added
credit: [MentalHomiega]
---

An infantry or vehicle type with `ClonedAt` now gets a free copy from each listed structure its owner has whenever a factory releases one, as Ares does, and cloning vats and cloning facilities no longer copy it. Types that leave the key out are cloned as before.

---
title: Shut vehicles down without a listed structure (PoweredBy)
category: feature
release: 0.2.0
targets:
- type: key
  id: PoweredBy
  effect: added
credit: [MentalHomiega]
---

A vehicle type can now name building types in `PoweredBy`, as Ares does. The vehicle shuts down while its owner has no working structure of a listed type. Types that leave the key out are unchanged.

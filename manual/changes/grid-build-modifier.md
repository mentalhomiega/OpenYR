---
title: Start sidebar cameos from the grid keys while a modifier is held
category: feature
release: 0.2.0
targets:
- type: command
  id: GridBuildModifier
  effect: added
credit:
- MentalHomiega
---

Holding the grid build modifier labels the sidebar cameos with the keys Q W E R, A S D F and Z X C V, in that order. While the modifier is held, one of those keys starts the build of its cameo and runs no other binding.

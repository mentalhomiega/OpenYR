---
title: Continue a waypoint path when a hovering jumpjet reaches a waypoint
category: fix
release: 0.2.0
targets:
- type: key
  id: BalloonHover
  effect: changed
credit: [MentalHomiega]
---

A Kirov, Siege Chopper or Rocketeer that is given a waypoint path now flies on to each following waypoint and ends on the last one. Before, it stopped at the first waypoint and stayed there.

With the modern [menu style](/keys/menustyle/), a greyed slider such as the Connection readout in the internet game options now keeps the modern shape instead of the classic grip. The game sets the connection timing itself, so the slider cannot be moved; its caption now says so in a tooltip, and the quality name reads "Fast (auto)" instead of naming the timing rung.

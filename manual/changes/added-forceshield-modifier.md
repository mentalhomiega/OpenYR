---
title: Scale or refuse the Force Shield with ForceShield.Modifier
category: feature
release: 0.2.0
targets:
- type: key
  id: ForceShield.Modifier
  effect: added
credit:
- MentalHomiega
---

`ForceShield.Modifier=` in a type section of `rules.ini` multiplies the length of a Force Shield put on objects of that type. At `0` or below the type is not shielded. The default is `1`.

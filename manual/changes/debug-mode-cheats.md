[`DebugMode=yes`](/keys/debugmode/), or the "Debug mode (for testing)" switch on the display options screen, turns on four cheat commands in the Debug category: infinite money, unlock everything, instant build and reveal map. They work only in campaign and skirmish games, and do nothing while the setting is off.

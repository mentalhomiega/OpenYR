title: Show the ion cannon shockwave where a warhead goes off (IonCannon.Ripple)
category: feature

targets:
- type: key
  id: IonCannon.Ripple
  effect: added
credit: [MentalHomiega]

A warhead with `IonCannon.Ripple` above 0 now shows the ion cannon's ground shockwave where it goes off, for that many frames of the wave, as a visual effect only. Warheads that leave the key out are unchanged.

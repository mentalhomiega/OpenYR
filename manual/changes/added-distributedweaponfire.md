---
title: Read the DistributedWeaponFire weapon key
category: feature
release: 0.2.0
targets:
- type: key
  id: DistributedWeaponFire
  effect: added
credit: [MentalHomiega]
---

A weapon now reads `DistributedWeaponFire` and keeps it in saved games, as Yuri's Revenge does. The key has no effect on how a weapon fires, in Yuri's Revenge or here, so no mission or mod plays differently. Saved games from before this change no longer load.

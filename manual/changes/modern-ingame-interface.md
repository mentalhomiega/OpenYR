title: Offer a modern in-game interface
category: feature
release: 0.2.0
targets:
- type: key
  id: InterfaceStyle
  effect: added
credit: [MentalHomiega]
---

[`InterfaceStyle=Modern`](/keys/interfacestyle/), or the "Modern in-game interface" switch on the display options screen, lets the map fill the screen, with the radar, credits, power and build cameos in one framed panel in the top-right corner and the command bar in the bottom-left corner. The classic sidebar stays the default.

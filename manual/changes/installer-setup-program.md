Testers can install OpenYR with `OpenYR-Setup.exe` instead of extracting the zip into their Yuri's Revenge folder. The setup finds an install of Yuri's Revenge in the registry, in the default Steam, Origin or EA App folders, or in a Steam library, and installs OpenYR into its own folder without administrator rights. Settings and saves are kept on an update, and the program can be removed from Apps & Features.

---
title: Give any soldier the cow's idle behaviour (IsCow)
category: feature
release: 0.2.0
targets:
- type: key
  id: IsCow
  effect: added
credit: [MentalHomiega]
---

A soldier type can now set `IsCow`, as Ares does, to idle and wander like the cow, even under human control. It defaults to yes for the type named `COW` and no for others, so stock rules are unchanged.

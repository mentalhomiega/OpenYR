The StructureTab, DefenseTab, InfantryTab and UnitTab commands show the sidebar tab of that name, as the stock command does. By default they are bound to Q, W, E and R, the keys the stock keyboard file gives them. A tab with nothing to build in it is not shown, and the key leaves the sidebar as it was.

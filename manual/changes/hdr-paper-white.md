---
title: Set the brightness of SDR white on HDR output
category: feature
release: 0.2.0
targets:
- type: key
  id: HDRPaperWhite
  effect: added
credit: [MentalHomiega]
---

[`HDRPaperWhite`](/keys/hdrpaperwhite/) sets the nits at which SDR white is drawn on an HDR display. It defaults to the SDR content brightness Windows reports for the display, and the Paper white slider on the Display page changes it while the game runs.

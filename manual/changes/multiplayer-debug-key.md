---
title: Toggle the multiplayer debug display with a key
category: feature
release: 0.2.0
targets:
- type: command
  id: MultiplayerDebug
  effect: added
credit: [MentalHomiega]
---

The new Multiplayer debug info command (Ctrl+I) shows or hides the multiplayer debug display in an IPX or Internet game. It works without starting the game with `-MPDEBUG`. A keyboard file saved earlier does not get the key; bind it on the keyboard dialog.

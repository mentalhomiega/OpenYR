The Classic scheme binds [Attack move](/commands/attackmove/) to Control with Shift held, the chord Yuri's Revenge uses. The controls screen can bind Shift, Control or Alt alone, and Control with Shift and a key. A keyboard file of version 4 or older gains the Classic binding unless another command holds that chord, and the dialog writes version 5.

A performance overlay shows the frame rates, graphs of the recent frame times and the time each part of a frame takes, over the top left of the map view. The [`PerfOverlay`](/commands/perfoverlay/) command (Ctrl+Shift+P) and the [`PerfOverlay=`](/keys/perfoverlay/) setting turn it on. A keyboard file saved before the command existed gains its key when it names no other command on it.

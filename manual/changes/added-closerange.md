`CloseRange=yes` is now read. An object with it accepts an approach spot within 1.2 cells of its target, and an infantryman moves to the free spot of a cell nearest the target. Stock rules set it on `BRUTE`, `DNOA`, and `MUMY`, which now close to melee distance.

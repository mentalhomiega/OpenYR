---
title: Keep an airborne or magnet-held object from starting to cloak
category: fix
release: 0.2.0
targets:
- type: system
  id: cloaking
  effect: changed
credit: [MentalHomiega]
---

An object that is above the ground, or that a locomotor warhead such as the Magnetron holds, no longer starts to cloak, as in Yuri's Revenge. A released Boomer begins to submerge only once it has landed.
